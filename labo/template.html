    Comment marche le Labo

    Nova reçoit exactement le prompt maître, la base de connaissances et le contexte du moteur de production. Seuls les outils sont simulés ici : la fiche, l'ébauche, l'appel et les alertes ne quittent pas cette page.

    Entrée envoie le message, Maj + Entrée va à la ligne, et une ligne vide sépare deux messages : le moteur les regroupe avant de répondre.

    Les réponses utilisent ton forfait Claude : aucune clé API n'est nécessaire.

    Tes avis sont enregistrés avec la conversation, pour que Claude puisse améliorer le prompt.
